# 📱 BudgetKu - Mobile Budget & Expense Tracker

> Aplikasi web pencatat keuangan harian yang ringan, ramah layar smartphone, dan menggunakan **Google Sheets** sebagai database gratis via **Google Apps Script**.

---

## ✨ Fitur Utama
- **⚡ Quick Add Transaction**: Input cepat ramah jempol dengan tombol kalkulator dan chip nominal (+10rb s/d +100rb).
- **💼 Multi-Dompet & Transfer**: Pisahkan uang tunai, bank, dan e-wallet, lengkap dengan fitur mutasi transfer antar akun.
- **📊 Anggaran Fleksibel**:
  - Batasan pengeluaran **Mingguan** & **Bulanan**.
  - Analisis makro **Metode 50/30/20** (*Needs / Wants / Savings*).
- **🔔 Tagihan Rutin (Recurring Bills)**: Pantau langganan bulanan (WiFi, Kos, Netflix) dan bayar dengan satu klik.
- **👁️ Privasi Saldo**: Sensor mata untuk menyembunyikan nominal saldo saat berada di tempat umum.
- **🌓 Dual Theme**: *Modern Dark Mode* (elegan & hemat baterai) dan *Clean Minimalist Light Mode*.

---

## 🏗️ Arsitektur Teknologi
- **Frontend**: HTML5, Tailwind CSS, JavaScript Modern (PWA Ready)
- **Backend**: Google Apps Script (Web App REST API)
- **Database**: Google Spreadsheet (5 Tab: `Transactions`, `Wallets`, `Categories`, `Budgets`, `RecurringBills`)
